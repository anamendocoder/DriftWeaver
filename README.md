# DriftWeaver

DriftWeaver is a Machine-Learning Engine that utilizes Cloud-Based architecture real-time data processing and auto-scaling on a scalable platform.

DriftWeaver is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DriftWeaver.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
